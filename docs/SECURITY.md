# Security policy

This tool reads local files that may contain wallet material. Treat its CSV
reports, caches, logs, and screenshots as sensitive because they can include
file paths and scan metadata.

Please do not post recovery phrases, private keys, complete scan reports, or
screenshots containing personal paths in public issues or discussions.

Report a vulnerability through GitHub's private vulnerability reporting when
it is enabled for this repository. Otherwise, contact the maintainers privately
before opening a public issue. Include the affected version, a concise impact
description, and a minimal reproduction that contains no real wallet secrets.

The current default branch is the supported version. Security fixes are made
there first; users should rebuild or download a package after a fix is released.
